# AgentGuard Security Console

Enterprise fintech operator console for monitoring autonomous AI buyer payments, inspecting invoice threat findings, enforcing spending policies, and settling PayPal `AUTHORIZE` escrow holds.

## Scripts

- `npm run dev` — Start local development server (proxies `/api` to `http://127.0.0.1:8000`)
- `npm run build` — Type-check and compile production static assets without source maps
- `npm run lint` — Run oxlint static analysis
- `npm run preview` — Preview production build locally
